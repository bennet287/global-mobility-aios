# Mobility User V2

## Primary navigation

- Overview
- My Case
- Documents
- Timeline
- Messages

## Goal

A case-first experience that answers:
- where am I?
- what happens next?
- what do you need from me?
- what has changed?

## Simplicity

Do not expose internal AIOS operational jargon unless required for transparency.

## Trust

Clearly distinguish:
- verified guidance
- professional review
- external authority decisions
- pending actions

## Privacy

Protected case records remain behind secure access.

## Spatial

Living Organization is not a required Mobility-user interaction. If shown at all, use only a lightweight, privacy-safe status metaphor.
