# Evidence V2

## Goal

Evidence should feel like evidence, not a generic record.

## Collapsed Evidence Object

Show:
- source
- title/claim
- verification
- freshness
- jurisdiction
- authority cue

## Expanded

Show:
- retrieval
- fingerprint
- SourceSnapshot
- linked VerifiedRules
- source authority
- professional review
- history
- dependencies

## Visual hierarchy

Primary:
what this evidence supports.

Secondary:
verification/freshness.

Deep:
technical provenance.

## States

Distinguish:
- verified
- pending review
- stale
- unsupported
- superseded/historical
- unavailable

No color-only meaning.
