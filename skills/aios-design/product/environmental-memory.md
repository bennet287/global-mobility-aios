# Environmental Memory V2

## Purpose

Reveal historical organizational patterns without claiming prediction or current authority.

## Structured view

Show:
- event-kind aggregates
- routing frequencies
- department/event heat
- hourly density
- coverage
- unsupported dimensions

## Spatial overlay

Optional:
- routing traces
- activity fields
- density layers

## Visual distinction

Memory mode must remain clearly different from:
- live
- Replay-as-of
- prediction

## Accessibility

All spatial memory views have structured analytical equivalents.
