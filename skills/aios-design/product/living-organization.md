# Living Organization V2

## Product role

Living Organization is the emotional center and organizational-understanding layer of AIOS.

It is not a separate fictional simulation.

It renders the same governed organization that structured UI exposes.

## Core layers

```text
Organization Presentation Model
        │
        ├── Structured Organization UI
        │
        └── Spatial Scene Model
              ├── HQ Architecture
              ├── Character Layer
              ├── Smart Objects
              ├── Selection
              ├── Ambient Motion
              └── Semantic Motion
```

## Interactions

- employee → Employee context/workspace
- Mission Room → Mission
- Evidence Object → Evidence
- Board Room → Decisions
- department → Department
- timeline → Replay
- memory lens → Environmental Memory

and be able to immediately inspect the proof behind that feeling.
