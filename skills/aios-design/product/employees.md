# Employees V2

## Employee identity

An AIOS employee is a persistent organizational identity.

Structured workspace may show:
- role
- department
- authority/seniority
- responsibility
- supported current state
- current Mission
- WorkItem
- blockers
- recent Activity
- conversations
- handoffs
- evidence/decision contributions
- technical runtime details behind disclosure

## Character link

The 3D character is the spatial representation of this identity.

## Technical disclosure

Provider/model/runtime/cost are not the first thing users see unless the task is technical governance.

## Presence

Do not translate “character visible” into literal presence claim.

## History

Employee historical state must use supported Replay dimensions only.
