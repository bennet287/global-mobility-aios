# Missions V2

## Mission as first-class product object

Mission workspace contains:
- purpose
- state
- phase
- sponsor/authority context
- participants
- WorkItems
- dependencies
- blockers
- Evidence
- Decisions
- conversations
- recent Activity
- next action
- history/Replay

## Progress

Use real stages/state.

Do not invent a percentage.

## Spatial

Mission Room represents the same Mission.

Spatial participants and objects must be supported by the Mission projection.

## Owner view

Highlight:
- what changed
- what is blocked
- what needs authority
- what evidence/decision matters

## Operator view

Prioritize:
- tasks
- dependencies
- evidence
- next work

Same Mission; different information depth.
