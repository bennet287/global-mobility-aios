# AIOS V2 Anti-Patterns

The following fail design review unless an explicit documented exception exists.

## UI
- generic SaaS card farm
- equal-weight KPI wall
- purple-gradient AI branding
- cyberpunk neon overload
- glow everywhere
- glassmorphism everywhere
- arbitrary rounded rectangles
- arbitrary one-off colors
- page-specific design systems
- raw backend/module taxonomy as primary navigation
- generic badges representing unrelated semantic states
- decorative charts
- huge empty hero areas that delay useful information

## UX
- more than a few equal-weight primary actions
- technical metadata before user meaning
- hidden uncertainty
- hover-only essential actions
- ambiguous destructive/authority actions
- navigation by memorizing route names
- 3D required for ordinary administrative work

## Characters
- generic humanoid avatars
- identical bodies with shirt-color role coding
- childish/baby-looking workforce
- photoreal uncanny-valley humans
- direct copying of existing animated franchises
- role identity dependent only on labels
- decorative “working” animation with no state basis

## Architecture
- pixel tower
- stacked apartment-office metaphor
- rooms as arbitrary boxes
- game-map layout
- unstable department locations that destroy spatial memory
- architectural effects with no navigational or organizational value

## Motion
- random perpetual animation
- semantic movement without canonical support
- fake meetings
- fake handoffs
- fake conversations
- animation that implies throughput/productivity not supported by data
- no reduced-motion equivalent
- jarring camera travel

## Governance
- recommendation styled as approval
- memory styled as live truth
- prediction styled as canonical
- renderer styled as authoritative
- partial history styled as complete
- missing evidence styled as confidence

## Engineering
- extending legacy global CSS indefinitely
- adding ungoverned breakpoints
- adding hardcoded V2 colors outside token/material exceptions
- large V2 pages that combine all data, state, layout, and domain translation without reusable boundaries
