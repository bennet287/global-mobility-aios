# Uncertainty UX

## Principle

Uncertainty is a product state, not an error to hide.

## Categories

- unknown
- unavailable
- unsupported
- stale
- partial coverage
- conflicting
- under review
- predictive uncertainty

## Presentation

Use:
- clear language
- restrained visual state
- explanation
- next action where meaningful

Avoid:
- vague “low confidence” badges without meaning
- red error treatment for ordinary partial coverage
- hiding unsupported dimensions

## Authority

Uncertainty should be particularly visible before high-stakes decisions.
