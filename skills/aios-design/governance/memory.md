# Environmental Memory UX

## M.9.1 posture

Environmental Memory remains:
- canonical projection
- non-authoritative
- non-predictive
- read-only
- visualization-only

## Presentation

Structured:
- kind aggregates
- route frequencies
- department/event heat
- temporal density
- coverage
- unsupported dimensions

Spatial:
- optional flow traces
- activity field
- density overlay

## Rules

- clearly label memory/aggregate mode
- never visually merge it with live current state
- preserve source Replay coverage
- do not extrapolate into prediction
