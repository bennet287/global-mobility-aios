# Prediction UX

## Principle

Prediction is not canonical truth.

## Presentation

Prediction must have a distinct visual/linguistic class.

Use labels such as:
- predicted
- forecast
- simulation
- scenario

where applicable.

## Forbidden

- placing prediction in deterministic scene without distinction
- using prediction to trigger semantic canonical animation
- presenting predicted employee work as actual work
- hiding uncertainty

## Interaction

Users can inspect:
- basis
- horizon
- confidence/uncertainty
- limitations

if such data exists.

If predictive capability is unavailable, show it as unavailable rather than synthesize it.
