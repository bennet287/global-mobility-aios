# Historical State UX

## Replay source

Historical state comes from supported Replay/as-of reconstruction contracts.

## Rules

- cursor/time visible
- coverage visible
- current vs historical visually distinct
- unsupported historical dimensions explicitly unavailable
- no mutation in historical mode

## Compare

A/B comparison should distinguish:
- appeared
- disappeared
- changed
- unchanged omitted where contract says so

## Spatial replay

The scene updates only from supported reconstructed dimensions.

Do not animate historical details absent from the contract.
