# Character Wardrobe Language

## Goal

Contemporary professional style with role personality.

## General rules

- original
- modern
- adult
- polished
- not uniform
- not costume
- not stereotype

## Executive
Refined tailoring, clean layers, subtle material quality.

## Technology
Architectural overshirts, jackets, technical knits, practical premium footwear.

## Security
Controlled, sharper, darker professional layers.

## Regulatory / Evidence
Precise, research-oriented professional styling with warmer detail.

## Operations
Practical, flexible, movement-friendly professional clothing.

## Accessories

Use sparingly:
- tablet
- notebook/evidence folio
- technical device
- headset only where contextually appropriate
- security display tool
- work object

Accessories are identity cues, not permanent clutter.
