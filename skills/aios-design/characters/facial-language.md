# Character Facial Language

## Goal

Expressive enough to feel alive, restrained enough to remain professional.

## Core expression set

- neutral attentive
- focused
- thoughtful
- waiting
- concerned/blocker attention
- collaborative
- satisfied/settled
- authority-attentive

## Rules

- no exaggerated cartoon distress
- no constant smiling
- no fake emotional claim stronger than canonical state
- ambient facial movement remains presentation-only
- blocker state may change attention, not invent panic

## Readability

Eyes, brows, mouth, and head angle should remain readable at miniature scale.

Facial style should harmonize across the organization while preserving individual identity.
