# Executive Role Direction

## CEO
- calm executive silhouette
- refined contemporary tailoring
- slower deliberate locomotion
- measured gestures
- strategy/briefing object
- Board/strategy spatial proximity

## CTO
- technical architectural silhouette
- overshirt/jacket instead of generic hoodie cliché
- analytical gesture rhythm
- system-surface interaction
- technical device

## CISO
- sharper geometry
- restrained movement
- vigilant gaze
- security display interaction
- controlled darker material language

## COO
- highly organized practical executive
- stronger operations proximity
- efficient gestures
- Mission/operations object interaction

## CFO
- calm analytical visual language
- financial evidence/overview objects
- deliberate numerically focused behavior

## Other C-suite
Each executive receives a specific silhouette/prop/motion language derived from the real role card.

No executive should be “same suit, different label.”
