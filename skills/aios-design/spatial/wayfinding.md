# Spatial Wayfinding

## Principle

Users should learn where organizational functions live.

## Cues

Use:
- stable layout
- architectural shape
- material differences
- room labels
- controlled department accents
- landmarks
- camera presets

## Desired memory

Users should learn:
- Board/executive location
- Regulatory/Evidence location
- Technology/Security relation
- central Mission Hub
- Operations location

## Avoid

- moving departments between sessions
- heavy game mini-maps
- excessive floating labels
- signage clutter

Wayfinding should emerge primarily from architecture and consistency.
