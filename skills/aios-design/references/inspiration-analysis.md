# Inspiration Analysis

## Character direction

Approved inspiration qualities:
- miniature readability
- expressive adult faces
- high-end animated-film polish
- distinctive role silhouettes
- contemporary professional wardrobe

Reject direct imitation of existing characters/franchises.

## Architecture direction

Approved qualities:
- premium architectural model
- atrium/terrace hierarchy
- stable department topology
- warm materials and greenery
- sophisticated embedded technology
- strong spatial memory

## UI direction

Approved qualities:
- premium operating-system restraint
- editorial hierarchy
- controlled materials
- contextual inspectors
- meaningful motion
- minimal generic dashboard chrome

Every future inspiration entry should describe transferable principles, not only screenshots.
