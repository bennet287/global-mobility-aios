# Environmental Smart Objects

## Purpose

Smart objects connect the architectural world to real AIOS entities.

## Classes

- Mission Object
- Evidence Object
- Source Object
- Decision Object
- Authority Object
- Risk/Blocker Object
- Work Object
- Conversation Object
- Handoff Object
- Replay Object

## Required contract

Each smart object defines:
- canonical/presentation backing
- object key
- state
- visual form
- selection behavior
- inspector behavior
- keyboard equivalent
- screen-reader equivalent
- reduced-motion behavior
- historical behavior
- unavailable behavior
- LOD behavior

## Rule

Do not introduce a visually authoritative object whose semantic backing is only decorative.
