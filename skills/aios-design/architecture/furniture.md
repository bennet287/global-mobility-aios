# Furniture Language

## Principle

Furniture supports role, work type, and architectural identity.

## Families

Executive:
- clean tables
- strategic surfaces
- refined seating

Technology:
- modular desks
- system/prototype benches
- technical displays

Regulatory:
- research tables
- evidence comparison surfaces
- archival/source display

Operations:
- shared worktables
- case stations
- Mission boards

Communal:
- soft seating
- coffee tables
- café surfaces
- planters

## Rules

- avoid excessive prop clutter
- prioritize silhouette/readability
- furniture should support interaction anchors
- repeated furniture should be optimized/instanced
