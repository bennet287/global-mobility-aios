# Headquarters Architecture

## Role

The headquarters is the stable spatial representation of the AIOS organization.

It must communicate:
- hierarchy
- departments
- collaboration
- authority
- Mission activity
- evidence work
- operations

without becoming a literal game map.

## Core composition

- Executive Terrace / Board
- Central Atrium
- Regulatory / Evidence wing
- Technology / Security wing
- Mission Hub
- Operations Studio
- Case / Client work areas
- Coffee / Lounge / Courtyard / Terrace

## Architectural character

Use:
- layered levels
- bridges
- open sightlines
- transparent boundaries
- curved circulation selectively
- greenery
- refined furniture
- warm controlled light
- technical surfaces embedded into architecture

## Scale

The HQ should read as a miniature diorama:
- compact enough for overview
- large enough for role/room distinction
- shallow enough to avoid excessive camera travel

## Stability

Major zones should remain spatially stable across sessions to support memory and wayfinding.
