# Board Room Architecture

## Character

The Board Room should feel:
- calm
- authoritative
- spacious
- low-noise
- deliberate

not theatrical.

## Spatial role

It represents:
- Board authority
- Owner decisions
- executive governance

## Normal state

Calm and visually quiet.

## Pending authority

May gain:
- restrained illumination
- one visible decision object
- subtle directional connection from affected Mission/work

Avoid:
- flashing red
- alarms
- excessive glow
- casino-like urgency

## Interaction

Selecting Board Room opens the Decisions/Board structured workspace.

High-stakes action remains in structured governed UI, not directly in 3D.
