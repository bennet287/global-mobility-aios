# AIOS V2 Office / World Bible

## World thesis

Retire the pixel tower and stacked-room metaphor.

AIOS V2 uses a **premium miniature architectural headquarters / campus / diorama**.

It should feel like an architect-designed model that has come alive, not a game level.

## Stable topology

Conceptual organization:

```text
                     EXECUTIVE TERRACE
                CEO Studio ─ Board Chamber
                         │
                   Strategy Lounge
                         │
                     CENTRAL ATRIUM
                         │
   REGULATORY / EVIDENCE ├── TECHNOLOGY / SECURITY
                         │
                     MISSION HUB
                         │
                   OPERATIONS STUDIO
                         │
             CASE / CLIENT / WORK AREAS
                         │
         COURTYARD · COFFEE · LOUNGE · TERRACE
```

The diagram expresses topology, not literal box geometry.

## Architectural language

Use:
- open atrium
- terraced levels
- bridges
- transparent partitions
- curved circulation where useful
- greenery
- refined furniture
- warm architectural lighting
- material contrast
- embedded technology
- collaboration areas
- focus areas
- authority spaces

## Department character

### Executive
Quiet, spacious, fewer objects, stone/wood/metal, strategy surfaces.

### Technology
Precision, modular furniture, system walls, prototyping surfaces, cooler task accents.

### Security
Controlled, focused, clear boundaries, low visual noise, disciplined darker materials.

### Regulatory / Evidence
Warmer library/research cues, evidence walls, source tables, comparison surfaces.

### Operations
Open, kinetic, shared tables, Mission boards, case stations, higher circulation.

### Communal
Coffee, lounge, courtyard, greenery, informal meeting areas, terrace, soft furniture.

Communal space is mandatory. It prevents the organization from feeling like employees stored inside functional boxes.

## Architecture as interface

The world communicates:
- department
- authority
- Mission context
- collaboration
- blockers
- evidence
- state
- wayfinding

Rooms and smart objects map to canonical or explicitly presentation-only entities.

## Spatial memory

Major rooms remain stable enough for users to learn:
- Board near/above executive atrium
- Regulatory in evidence wing
- Security near Technology
- Mission Rooms central
- Operations connected to active case work

Do not procedurally rearrange core topology.
