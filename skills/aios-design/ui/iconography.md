# AIOS V2 Iconography

## Goal

One coherent icon language across AIOS.

## Core semantic families

- Home
- Organization
- Mission
- Employee
- Department
- Work
- Evidence
- Source
- Decision
- Authority
- Blocker
- Risk
- Conversation
- Handoff
- Replay
- Compare
- Memory
- Prediction
- Automation
- Human Review
- External Source
- External Authority
- Technical / Provider
- Search / Command

## Style

Prefer:
- clean geometry
- consistent stroke/weight
- readable at compact sizes
- restrained detail

## Rules

- icon meaning must be stable
- unfamiliar icons pair with labels
- status meaning cannot depend on icon alone
- do not mix unrelated filled/outlined sets arbitrarily
- inline SVGs should eventually derive from a governed source/registry

Whether AIOS uses a curated icon library or custom icons remains open pending prototype review.
