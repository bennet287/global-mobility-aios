# AIOS V2 Layout & Grid

## Principle

AIOS does not have one universal dashboard grid.

It has a family of workspace compositions.

## Layout families

### Executive Situation
For Owner Home.

Priorities:
- situation
- needs attention
- organization preview
- Missions
- recent change

### Domain Overview
For Intelligence, Evidence, Decisions, Organization.

### Mission Workspace
Mission identity, participants, work, blockers, evidence, decisions, history.

### Evidence Workspace
Source/evidence list + focused inspector/comparison.

### Decision Workspace
Decision context + authority + evidence + history.

### Employee Workspace
Identity, Mission/work, blockers, activity, conversations, technical disclosure.

### Operator Dense Workspace
Tables, queues, filters, forms, local navigation.

### Mobility User
Simple case-first layout.

### Spatial + Structured
Scene viewport with contextual inspector.

### Replay / Compare
Temporal control + structured/spatial reconstruction.

## Composition rules

- avoid uniform card mosaics
- create clear focal region
- reserve whitespace around authority-critical decisions
- use asymmetric composition when it improves hierarchy
- support local navigation without shrinking content excessively

## Content width

Exact widths are tokens, not per-page inventions.

## Responsive behavior

Layouts transform by semantic priority, not by mechanically stacking every desktop panel.
