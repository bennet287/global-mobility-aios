# AIOS V2 Data Visualization

## Principle

Every visualization answers a specific question.

## Core domains

- Mission stages
- Work flow
- evidence lineage
- risk
- confidence/uncertainty
- activity
- routing
- cost
- organizational topology
- Replay
- Environmental Memory

## Rules

- explicit units where relevant
- accessible text/table equivalent where needed
- semantic color consistency
- uncertainty visible
- aggregation labeled
- current vs historical clearly separated
- no decorative chart for one number
- no 3D chart if 2D is clearer

## Environmental Memory

Memory heat/flow must be labeled as historical aggregate.

## Replay

Temporal visualizations must respect coverage and unsupported dimensions.

## Executive visualization

Prefer a clear narrative/situation over a dense chart wall.
