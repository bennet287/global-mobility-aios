# AIOS V2 Materials

## Selected material language

**Architectural, restrained, premium.**

Use:
- graphite/ink
- warm stone/off-white
- smoked glass
- refined wood cues in architecture
- brushed/soft metal detail
- subtle translucent HUD surfaces
- controlled soft shadow

## UI materials

### Base
Opaque and comfortable for reading.

### Raised
Slight depth for interactive domain objects.

### Inset
Evidence/provenance/detail wells.

### Floating
Inspector, command palette, spatial HUD.

### Authority
Calm but distinct, with stronger structural emphasis.

## Glass rule

Translucency is primarily for:
- floating HUD
- transient overlay
- command palette
- spatial inspector

Do not use glass for every card.

## Glow rule

Glow is not a base material.

Use only where it communicates:
- spatial focus
- selected object
- bounded attention

and remain subtle.

## Architecture relation

UI overlays should visually harmonize with the HQ material system without imitating physical materials literally.
