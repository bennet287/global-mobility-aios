# AIOS V2 Visual Identity

## Selected direction

**Contemporary architectural luxury + premium operating-system restraint.**

The UI should feel:
- expensive without ostentation
- modern without trend-chasing
- calm
- precise
- intelligent
- alive
- trustworthy

## Foundation palette direction

Use semantic tokens rather than fixed page colors.

Visual direction:
- deep graphite / ink
- warm off-white / stone
- smoked translucent overlays
- fine metallic/champagne detail
- restrained cool technical accents
- controlled department accents

Exact values remain open until prototype validation.

## Reject
- generic purple AI identity
- cyberpunk
- neon outlines everywhere
- hologram spam
- glow overload
- decorative glass
- card-grid sameness

## Typography

Geist / Geist Mono are strong baseline candidates.

Identity should come from:
- hierarchy
- scale
- tracking
- line length
- editorial composition
- numeric styling
- mono technical disclosure

Required roles:
- display
- page title
- section
- object title
- body
- compact body
- label
- caption
- metadata
- numeric
- status
- provenance/technical

## Material hierarchy

Define:
1. canvas
2. base work surface
3. raised object
4. inset detail
5. floating inspector
6. authority surface
7. spatial HUD
8. transient notice
9. technical disclosure

Translucency is mainly for floating/transient layers.

## Radius/depth

Radius and shadows indicate material role, not generic modernity.

No arbitrary V2 radius/shadow values outside tokens.

## Domain-native composition

Prefer:
- Mission
- Employee
- Evidence
- Decision
- Authority
- Handoff
- Department
- Temporal Lens

over:
- card
- card
- pill
- panel
- another card

## Theme

Support:
- light
- dark
- system

Dark mode must not become neon mode.

3D environmental lighting is independent from UI semantic theme.
