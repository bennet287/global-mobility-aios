# AIOS V2 Elevation

## Purpose

Depth communicates hierarchy, interaction, and context.

## Levels

### E0 — Canvas
No elevation.

### E1 — Base Surface
Primary work layer.

### E2 — Raised Domain Object
Selectable Mission/Evidence/Decision object.

### E3 — Inspector
Floating contextual detail.

### E4 — Authority / Dialog
High-priority governed interaction.

### E5 — Spatial HUD / Temporary System Layer
Used sparingly.

## Rules

- depth is semantic
- shadows remain soft
- avoid large dramatic shadows on routine objects
- dark mode uses contrast/material separation, not only stronger shadows
- 3D scene depth and UI elevation are separate systems

Exact shadow values live in tokens.
