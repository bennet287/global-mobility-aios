# AIOS V2 Spacing

## Principle

Spacing creates hierarchy and rhythm.

It is not arbitrary padding between rectangles.

## Candidate scale

Prototype candidate:

`4, 8, 12, 16, 24, 32, 48, 64, 96`

Not locked until prototype review.

## Use

- micro spacing for icon/label relationships
- compact spacing for dense work
- standard spacing for domain objects
- large spacing for major sections
- generous spacing for authority/executive focus

## Rules

- related items are closer than unrelated items
- primary action groups are visually distinct
- provenance metadata should not visually crowd primary meaning
- dense tables use consistent row rhythm
- spatial HUD uses tighter rhythm than long-form structured content

Avoid adding new one-off values without a design reason.
