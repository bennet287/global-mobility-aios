# AIOS V2 Responsive UI

## Target modes

- wide desktop
- desktop
- laptop
- tablet landscape
- tablet portrait
- mobile
- low-power
- reduced motion
- renderer fallback

## Principle

Responsive design re-prioritizes information.

It does not merely shrink or stack desktop UI.

## Owner Home

Desktop:
- situation + attention + organization preview

Mobile:
- attention
- Mission state
- structured organization snapshot

## Spatial

Desktop:
full scene + contextual inspector.

Tablet:
focused scene + sheet inspector.

Mobile:
structured organization first; optional compact visual preview if performant.

## Dense Operator Work

Preserve tables and forms where useful:
- horizontal scroll only when necessary
- responsive columns
- local summaries
- compact actions

## Breakpoints

Use governed token modes; exact values are locked only after prototype validation.
