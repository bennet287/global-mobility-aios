# Handoff Motion

## Canonical source

Use supported handoff/assignment records only.

## Visual grammar

Possible sequence:
1. sender receives emphasis
2. Work Object appears/activates
3. transfer path communicates direction
4. receiver receives object/focus
5. final state settles

## Common fate

The moving work object and receiver orientation may communicate the relationship without permanent arrows.

## Forbidden implications

Do not imply:
- physical transfer duration is real
- conversation happened
- work is complete
- dependency resolved
- human approval happened

## Reduced motion

Static sender → receiver relation plus brief focus transition.
