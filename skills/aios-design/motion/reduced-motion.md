# Reduced Motion

## Principle

Reduced-motion mode is a designed experience, not “disable CSS animation and hope.”

## Replace

- camera glide → short cut/fade
- long handoff travel → static relationship + brief emphasis
- looping ambient motion → mostly static pose
- parallax → fixed composition
- large transforms → opacity/border/state changes

## Preserve

- state change
- selection
- authority
- blocker
- evidence status
- temporal difference
- Mission relationship

No essential meaning is lost.
