# Semantic Animation

## Purpose

Semantic animation expresses supported organizational relationships/state.

## Candidate mappings

- WorkItem assignment → handoff/transfer
- canonical conversation → participant collaboration
- Mission participation → Mission Room association
- blocker → attention state
- awaiting Owner → authority attention
- Board event → Board emphasis
- completion → settled/closure behavior

## Requirements

Every mapping has:
- canonical input
- required coverage
- visual interpretation
- forbidden implication
- reduced-motion equivalent
- replay behavior
- automated tests

## Rule

If support is ambiguous, use neutral presentation instead of guessing.
