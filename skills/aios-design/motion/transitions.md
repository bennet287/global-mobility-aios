# UI & Spatial Transitions

## Goals

Transitions preserve:
- origin
- destination
- hierarchy
- selection continuity
- temporal continuity

## Patterns

### Inspector open
Selected object remains visually anchored while inspector appears.

### Domain navigation
Use restrained crossfade/position continuity.

### Spatial focus
Short camera glide or reduced-motion cut.

### Mission activation
Use supported state cue, not cinematic spectacle.

### Evidence verification
Subtle settle/resolve treatment.

### Decision resolution
Reduce visual tension; preserve decision history.

## Avoid

- long full-screen transitions
- decorative page wipes
- motion that delays work
