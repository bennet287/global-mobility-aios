# AIOS V2 Information Architecture

## Principle

Primary navigation follows the user's mental model, not the repository/module inventory.

The existing route set remains available during migration, but persistent navigation is simplified.

## Owner

Primary:
- Home
- Organization
- Missions
- Intelligence
- Evidence
- Decisions
- History

Contextual:
- Owner Inbox
- Validation
- Source Review
- Agent Governance
- Automation
- Friction
- Department Workspaces

## Professional / Operator

Primary:
- Work
- Profiles
- Pathways
- Evidence
- Communication
- Tools

Contextual:
- Authority operations
- specialist domain workspaces
- agent coaching
- automation
- external validation

## Mobility User

Primary:
- Overview
- My Case
- Documents
- Timeline
- Messages

Internal AIOS implementation/governance vocabulary should only appear when transparency requires it.

## Navigation layers

1. experience
2. primary domain
3. local domain navigation
4. contextual entity inspector
5. command/search

## Information depth

- L0 Ambient
- L1 Attention
- L2 Context
- L3 Evidence
- L4 Provenance/Internals

## Route migration

Do not delete a route simply because it disappears from persistent navigation.

Migration may use:
- contextual links
- local navigation
- aliases
- redirects
- command palette
- entity deep links

until compatibility is proven.
