# AIOS V2 UX Laws

## Hick's Law
Reduce simultaneous choices.

Rule:
Primary focused surfaces should normally expose no more than three equal-weight primary actions.

Use contextual actions, local navigation, and command/search for the rest.

## Fitts's Law
Make important targets easy to acquire.

Rules:
- generous pointer/touch targets
- large invisible hit volumes for small spatial objects
- critical controls should not require pixel-perfect interaction

## Jakob's Law
Use familiar interaction patterns for familiar tasks.

AIOS may look unique while still using recognizable:
- navigation
- search
- forms
- filters
- tables
- drawers
- confirmation
- keyboard focus

## Miller / Working Memory
Chunk complex state.

Do not force users to memorize:
- internal IDs
- long state lists
- route names
- hidden relationships

## Tesler's Law
Complexity cannot disappear.

Move it to the correct layer:
- meaning
- context
- evidence
- provenance

## Doherty Threshold
Acknowledge interaction immediately.

Use:
- immediate pressed/selected state
- truthful loading state
- progressive scene loading
- non-blocking shell

Numeric performance targets become contracts only after prototype measurement.

## Von Restorff Effect
Reserve visual exception for real exception:
- Owner action
- Board authority
- critical blocker
- material risk
- failed evidence
- critical unavailable state

Routine information must remain visually calm.

## Serial Position Effect
Place the most important items where scanning naturally starts and the decisive next action where task completion naturally ends.

## Peak-End Rule
Polish high-salience moments:
- Mission completion
- handoff
- Board decision
- evidence verification
- replay comparison
- error recovery

## Goal Gradient
Show real stages and remaining work.

Never invent percentages when the domain cannot truthfully compute them.

## Zeigarnik Effect
Unfinished authority/blocker/evidence work remains discoverable without becoming permanently intrusive.

## Aesthetic–Usability Effect
Visual quality improves comprehension and trust, but cannot compensate for bad task structure.

## Occam's Razor
Use the simplest adequate representation.

Do not use 3D, charts, or animation when a simple structured answer is better.

# Gestalt

## Proximity
Related entities should be visually/spatially near.

## Similarity
Same semantic classes share visual grammar.

## Common Region
Departments, Mission contexts, Evidence groups, and Board contexts use meaningful regions.

## Continuity
Flows, handoffs, navigation, and time preserve directional continuity.

## Figure/Ground
The active object is obvious.

## Common Fate
Shared movement communicates supported relationship.

This can become a signature AIOS spatial principle.

# Cognitive ergonomics

Design reviews explicitly consider:
- cognitive load
- decision fatigue
- interruption cost
- working memory
- recognition vs recall
- change blindness
- inattentional blindness
- context switching
- spatial memory
- trust calibration
