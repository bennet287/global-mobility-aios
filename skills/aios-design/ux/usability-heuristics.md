# AIOS V2 Usability Heuristics

Apply Nielsen-style heuristics to AIOS-specific workflows.

1. **Visibility of system status** — loading, partial, unavailable, authority, and canonical state are visible.
2. **Match to real-world mental model** — use Mission, Evidence, Decision, Employee, Case; avoid backend implementation jargon in primary UX.
3. **User control** — navigation/selection is reversible; authority changes are explicit.
4. **Consistency** — same domain object behaves the same across views.
5. **Error prevention** — high-stakes actions require clear boundaries and confirmations.
6. **Recognition over recall** — stable navigation, spatial memory, clear object identities.
7. **Efficiency** — keyboard, command palette, contextual tools.
8. **Minimalist design** — information earns screen space.
9. **Error recovery** — explain and preserve context.
10. **Help/documentation** — provenance, evidence, and technical detail available on demand.

Additional AIOS heuristic:

> Never let visual polish outrun authority/truth clarity.
