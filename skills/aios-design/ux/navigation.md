# AIOS V2 Navigation

## Layers

1. Experience switch
2. Primary domain
3. Local domain navigation
4. Context/entity navigation
5. Search/command

## Experience switching

Preserve:
- Owner / Board
- Professional / Operator
- Mobility User

Switching experience changes product context, not backend authority.

## Primary navigation

Keep short and stable.

Avoid using the sidebar as a list of every route.

## Local navigation

Complex domains such as:
- Evidence
- Intelligence
- Corporate Mobility
- Documents

should use local sections/tabs/rails.

## Breadcrumb/context

Use when hierarchy is meaningful:
`Evidence → Source → Snapshot`

Avoid breadcrumbs as decoration.

## Back behavior

Preserve context when moving:
scene → inspector → full workspace → back.

## Command/search

Power users should be able to jump directly to entities and tools without expanding the primary rail.
