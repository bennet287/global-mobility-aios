# Responsive Quality

## Modes to validate

- wide desktop
- desktop
- laptop
- tablet landscape
- tablet portrait
- mobile
- low-power
- reduced-motion
- renderer fallback

## Acceptance

A layout passes when:
- primary task remains obvious
- no essential action is hidden
- no unreadable tiny control
- no accidental horizontal page overflow
- inspector/navigation remain operable
- spatial content degrades gracefully

## Mobile principle

Recompose by priority.

Do not stack every desktop panel into an endless vertical page.
