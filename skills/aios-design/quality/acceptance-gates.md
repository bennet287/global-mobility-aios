# AIOS V2 Acceptance Gates

## Foundation gate
- tokens defined
- primitives defined
- themes work
- accessibility primitives pass
- no uncontrolled V2 CSS drift

## Owner Home gate
User can answer:
- what is happening?
- what needs me?
- what is the organization doing?

in the first viewport.

## Character gate
Role/seniority broadly readable without labels; characters remain adult/professional and original.

## HQ gate
Architecture is legible and spatially memorable at default camera.

## Living Organization gate
No semantic animation without backing state; structured fallback remains fully usable.

## Evidence/Decision gate
Authority and provenance are clear; high-stakes actions are protected.

## Replay gate
No unsupported history is visualized as supported.

## Accessibility gate
Keyboard, screen reader smoke, 200% zoom, reduced motion, touch, fallback.

## Performance gate
Measured prototype thresholds pass.

## Distinctiveness gate
The experience is recognizably AIOS rather than generic SaaS.
