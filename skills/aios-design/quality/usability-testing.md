# Usability Testing

## Owner tasks

Test:
- identify what needs attention
- inspect a Mission
- inspect an employee
- review evidence
- review a Board decision
- replay history

## Operator tasks

Test:
- find active work
- inspect blockers
- verify evidence
- compare pathways
- complete review/authority workflow
- communicate

## Mobility tasks

Test:
- understand case state
- identify missing document
- see next action
- inspect timeline
- read/send message

## Metrics

Use:
- completion
- time
- first-click correctness
- errors
- confidence/comprehension
- qualitative feedback

## Prototype gate

Do not mass-migrate until the vertical slice demonstrates clear improvement over legacy for representative tasks.
