# LangGraph Workflows

LangGraph is an optional workflow research candidate for state, retries, branching and human approval. The current code is a non-production intake skeleton; it is not used by the accepted J/K/L organization runtime and its checkpoint state is never canonical AIOS WorkItem, organization, authority or Activity truth.

Historical candidate graphs:

1. lead_intake_graph
2. visa_truth_review_graph
3. document_completeness_graph
4. recruitment_application_graph
5. education_shortlist_graph

API skeleton exists in `apps/api/app/workflows/intake_graph.py`.

Do not expand this skeleton until a measured product/runtime gap justifies an R3 evaluation under `docs/TECHNOLOGY_RADAR_V1_3_6.md`.
