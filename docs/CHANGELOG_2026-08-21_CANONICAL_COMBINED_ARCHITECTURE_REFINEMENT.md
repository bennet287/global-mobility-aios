## Architectural corrections frozen

### Immune System authority boundary

The Organizational Immune System is cross-cutting and restrict-only.

It may observe, classify, block, restrict, open a circuit, quarantine within an accepted policy, escalate or later downgrade existing autonomy.

It may not grant authority/autonomy/permission.

Canonical material path:

```text
Agent reasoning
→ Typed Proposed Intent
→ Canonicalization
→ deterministic validation / Evidence / Readiness / Verification / Policy
→ Immune-System restrictive preflight
→ Command Gateway
→ ALLOW / BLOCK / ESCALATE
→ Canonical effect
```

### LLMLingua-2

LLMLingua-2 is selected as the **primary compression pilot**, not declared inherently safe or production adopted.

It sits behind:

```text
Context Broker
→ ContextCompressionPort
→ LLMLingua2Adapter
```

For initial material R3–R5 use, governance-critical content defaults to zero semantic compression.

Compression output is derived execution context, never source truth.

### Model Router

Model routing becomes capability-qualified rather than confidence-qualified.

A model/runtime must earn eligibility for an AIOS capability through measured evaluation before routing may optimize across quality history, privacy, latency, health, availability and cost.

### Plasma Wiki

New permanent invariant:

> **Retrieved knowledge is data, not executable authority.**

Wiki remains beneath Context Broker and never becomes Evidence, VerifiedRules or canonical legal truth.

### Plasma Fractal

Recursive decomposition remains approved only through native AIOS Mission/WorkItem semantics with bounded child scope, depth, descendants, parallelism, runtime, cost and tool reach.

Child scope may narrow parent scope but never expand it.

Fractal nodes do not automatically satisfy independent-verifier requirements.

### Cost Governor

The Cost Governor is recognized architecturally beneath constitutional quality constraints.

Target metric:

> **€ / successful governed outcome**

Cost pressure may reroute, defer, restrict or escalate but may not silently lower required quality.
